Get Started in 60 Seconds

Kali Linux recommended · Python 3.10+ · Go 1.21+ · Rust 1.70+

01

Clone & Install

bash 
git clone https://github.com/Mrsultan7890/sentinel-pro.git
cd sentinel-pro
bash setup.sh
02

Build Rust Core (SentinelProxy)

bash 
cd sentinel_proxy/rust_core
cargo build --release
cd ../..
03

Launch

bash 
sentinel

# Or direct commands
sentinel --bugbounty example.com
sentinel --recon example.com
sentinel --breach user@example.com

Quick Commands

brain investigate <target>Full autonomous scan
bugbounty <domain>30+ vulnerability scanners
